Komet is a client-side performance mod. It rewrites the hot paths of the render loop — the visibility sweep, occlusion culling, draw-range batching, and smooths the rest of the experience: chunk loading, stutter from GC pressure and driver syncs, shadow artefacts, VRAM held by empty pools. All without changing what ends up on screen: on every build the culling core is verified byte-identical against vanilla (3,120/3,120 checks) before anything is timed. The render-loop gains grow with view distance — which is why the measurements below were taken at view distance 1536, where vanilla struggles most.

Every number below was measured, not estimated, either in-game with the mod's built-in stress test and .komet report, or in the mod's benchmark on real game data structures. Where a vanilla figure does not exist, this page says so instead of inventing one.

Same scene, one switch: the visibility sweep

The built-in stress test flips one feature at a time back to the vanilla code path, in the same loaded scene (view distance 1536, standing), with interleaved baselines so scene drift cancels out. The biggest single item is the visibility sweep — the per-frame test of which mesh parts are on screen; at this view distance the engine tests several hundred thousand of them per frame:

Why you can trust the numbers

  • 3,120/3,120 culling test sweeps produce byte-identical triangles, in identical order, to vanilla — checked on every build.
  • 2,304/2,304 gap-merge checks stay pixel-equivalent.
  • Every optimisation is individually toggleable in komet.json; .komet safemode flips everything that affects what is drawn back to vanilla, live, for A/B checks mid-session.
  • Stress-test deltas use interleaved neighbour baselines, so linear scene drift cancels out exactly; deltas smaller than their ± spread are reported as noise.

How the comparison is computed: ×-factors are vanilla ÷ Komet; percentages are (vanilla − Komet) ÷ vanilla for times and (Komet − vanilla) ÷ vanilla for rates and fps. Test machine: 12-thread CPU, AMD Radeon RX 9070 XT, Linux/Mesa, Vintage Story 1.22.7, view distance 1536 unless stated. Absolute numbers scale with view distance and hardware: the render-loop gains grow with view distance, while the loading, stutter and GC improvements apply at any distance.

What Komet actually changes

  • Visibility sweep: spatial grid per mesh pool, AVX2 kernel, own worker threads, bit-identical results.
  • Occlusion culling: parallelised and moved off the main thread.
  • Draw-range merging incl. bridging over frustum-clipped gaps → fewer, larger GPU batches.
  • Distance culling for block-entity renderers, the engine ignores their own RenderRange.
  • Chunk loading: adaptive inflow brake, tesselation-thread tuning, neighbour prefetch, window pipelining — and visible border holes are repaired first, ahead of not-yet-visible chunks.
  • Shadows: texel snapping against crawling shadow edges, optional distance/quality knobs.
  • VRAM: empty mesh pools are reclaimed; GC pressure reduced (mesh buffer recycler, clone compaction).
  • Measurement built in: F7 HUD, hitch log, per-renderer profiler, stress test, .komet report.

Compatibility

  • A plain Harmony mod, zero setup. Komet patches the stock engine in memory when it loads — no forked client, no separate installer, no downloaded or decompiled game data (in contrast to fork-based optimisers such as Optimum, which install a separate patched client). Drop the zip into Mods; delete it to uninstall.
  • Shader mods (e.g. Sheydermod). Komet replaces no shader or asset files — its changes are engine-side code patches, so shader packs keep their visuals on top of it.
  • Server-side optimisers (e.g. Tungsten). Komet works the client’s render loop; server-side mods work the server tick, different halves of the game, so they are expected to combine cleanly. Not yet formally tested together — reports welcome.

Install: drop the zip into your Mods folder. Needs Vintage Story 1.22.0 or newer; built and verified against 1.22.7 — on other 1.22.x builds any patch whose engine code changed logs a warning and switches itself off individually, the game keeps running vanilla in that spot. In game: F7 toggles the performance HUD, .komet prints the numbers in chat, .komet report writes the full diagnostic block to the log, .komet safemode reverts all visual changes live. HUD and chat output are currently German. Client-side; safe to add or remove at any time.
